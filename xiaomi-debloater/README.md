# Xiaomi Debloater Android

Aplicativo Android planejado para identificar e gerenciar aplicativos preinstalados em dispositivos Xiaomi, Redmi e POCO.

## Diretrizes
- Kotlin e Jetpack Compose.
- Shizuku quando disponivel, com consentimento do usuario.
- Modo de analise sem privilegios.
- Nenhuma remocao automatica de pacotes desconhecidos ou essenciais.
- Preferir desativacao e restauracao; operacoes reversiveis quando suportadas.
- Validar compatibilidade por aparelho e versao Android/MIUI/HyperOS.

Status: estrutura inicial; APK ainda nao implementado.
